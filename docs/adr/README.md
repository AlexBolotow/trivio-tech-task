# Architecture Decision Records

ADR фиксирует долгоживущее архитектурное решение, его контекст, рассмотренные варианты и последствия.

Имена файлов:

```text
NNNN-short-decision-title.md
```

Статусы: `Proposed`, `Accepted`, `Superseded`.

Принятый ADR не редактируется так, чтобы менять смысл исторического решения. Новое решение оформляется следующим ADR и ссылается на заменённый документ.
