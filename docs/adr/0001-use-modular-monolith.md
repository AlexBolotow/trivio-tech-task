# ADR-0001: Use a modular monolith

- Status: Accepted
- Date: 2026-09-25

## Context

Trivio объединяет каталог, интеграции поставщиков, availability, бронирование, импорт, matching и поиск. У этих областей разные модели и темп изменений, но на учебном этапе нет операционной причины разворачивать отдельные сервисы.

## Decision

Использовать один Laravel deployment с модульной организацией package by feature. Внутри бизнес-модуля по мере необходимости выделять `Domain`, `Application`, `Infrastructure` и `UI`. Взаимодействовать между модулями через публичные контракты и события, не обращаясь к их внутренним классам.

## Alternatives

- Обычное Laravel-приложение package by layer.
- Набор микросервисов по предполагаемым bounded contexts.

## Consequences

- Локальная разработка, транзакции и deployment остаются простыми.
- Границы модулей требуют дисциплины и архитектурных тестов.
- Отдельный модуль можно будет выделить в сервис позже, если появится измеримая причина.
