# Specifications

`specs/` содержит актуальное поведение системы по capability.

`changes/` содержит активные change-пакеты:

```text
proposal.md
specs/<capability>/spec.md
design.md
tasks.md
```

После реализации изменение проверяется против спецификации, архивируется, а актуальная capability specification обновляется.
