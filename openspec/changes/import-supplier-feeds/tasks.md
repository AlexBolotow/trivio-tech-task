# Задачи: импорт файлов поставщиков

- [ ] Рассмотреть и одобрить proposal.md, включая объём первого этапа и то, что в него не входит.
- [ ] Выбрать хранение исходных данных: общие таблицы поставщиков, отдельные staging-таблицы или исходные файлы плюс общие записи.
- [ ] Решить, как получать ограниченные chunks из однострочного XML и нужна ли параллельная обработка этого файла на первом этапе.
- [ ] Определить статусы batch/chunk, поля lease, период heartbeat, лимит повторов, политику ошибок и карантина.
- [ ] Определить инвариант активации версии, чтобы неудачный полный импорт не заменял активные данные.
- [ ] Определить публичный контракт между Import, SupplierIntegration, Matching и Catalog.
- [ ] После одобрения дизайна добавить миграции схемы и контракты модулей.
- [ ] Реализовать один вертикальный поток импорта с идемпотентной обработкой chunks и MySQL integration-тестами.
- [ ] Добавить readers обоих форматов поставщиков и тесты на синтетических NDJSON/XML-файлах.
- [ ] Проверить новый импорт, повторный chunk, частичный сбой и повтор, некорректную запись, неудачный batch и атомарную активацию.
- [ ] Сверить реализацию с одобренными spec/design и архивировать change.
